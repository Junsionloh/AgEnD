# Main tasks the person confirms, and the person told (screenshots)

Taken on the preview of `preview/agend-377` (`6de95da`): desktop (1440×900) and phone (390×844 @2×) × light / dark × English / 繁體中文.
The language is the host's preference, so the English shots rewrite the page's language in what the browser reads; nothing is changed on the host.

| File | What it shows |
|---|---|
| `*-settings.png` | Settings › Shared agent settings › Advanced: the new switch **Main tasks wait for you to confirm them** (`defaults.task_board.person_confirms_main`), turned on, with its one-line explanation. |
| `*-notices.png` | The Notices page with a **Task** notice (a main task that finished by itself, what it still lacks, who is asked to fill it in), with **Open the card** and the owner's chat. |

The ▯ in front of a notice is the emoji (✅ / 🔔) that the headless browser used here has no font for; a real browser draws it.
The notice sentences are in the fleet's language (English on this preview), the page around them in the page's.
The names on these shots (agents, cards) are the preview's own; they are not for an upstream PR as they are.
