- **A terminal agy takes an interjection into the running turn (#3731).** `/steer`, Ctrl+Enter in the web chat and `steer: true` now work for an `antigravity` instance that runs in tmux (agy 1.4.0 or later), where they used to be queued with "does not take interjections". agy sends a message by its own `Queued Messages` setting; AgEnD types the text and presses `Alt+M` (which sends with the opposite of that setting) under the default `queue`, and a plain Enter under `send-immediately`. Either way the tool that is running is not cancelled: the message reaches the agent before its next model call and the bubble says "Interjection · sent into this turn". agy reads the setting only when it starts, so a settings file edited since (or a setting that cannot be read) makes the steer queue as before until the instance restarts. An ordinary message is unchanged; a Windows native pane has no `Alt+M`, so there the steer is offered only under `send-immediately`.
