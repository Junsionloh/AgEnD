- **設定 → 帳號：從儀表板登入 Antigravity，主機和配對的 Windows 電腦都可以（AGEND-113）。** Antigravity 的預設登入現在和 Claude Code 一樣有「登入」／「重新登入」：儀表板執行 `agy acp --login`（需要 agy 1.5.0 或更新），顯示 Google 的連結，並接收你貼回的代碼；只有指令以 exit 0 結束、而且 `agy models` 能用，才算登入成功。每台配對電腦有一列自己的 Antigravity：Windows 每個 Windows 使用者只有一個 Antigravity 登入，所以在那裡登入會**取代那台電腦自己的 Antigravity 登入**（網頁會先確認，`agend-runtime remote-setup accounts on` 也會這樣說明）。這是電腦上「只能登入具名帳號」規則的唯一例外，而且只限 Antigravity；仍然要有擁有者在本機打開 `accounts` 開關、一次只能一個登入、十分鐘逾時、並寫進稽核紀錄。主機上的那一列會顯示登入的帳號（從 agy 自己的 token 檔讀出、遮罩後的 email，只在本機讀取），用量則顯示兩個額度池中用量最高的那一個並標出名稱；網頁登入完成後會立刻重新讀一次用量（沿用用量面板自己的更新限制）。只做 Google 帳號（訂閱）登入；不做 Google Cloud 專案、API key、具名帳號或登出。較舊的 agy 維持「在主機上登入」並提示更新；第一次安裝頁面和聊天裡的 `/login agy` 不變。**請把伺服器和 Runtime 一起升級：**Runtime 現在會回報 `signin-antigravity`，伺服器不會對沒有回報的 Runtime 提供那台電腦的 Antigravity 登入。
