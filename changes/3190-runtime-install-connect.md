section: Changed
---
- **Windows one-line install now connects too.** Pasting the Windows (PowerShell) command from Settings → Runtime → Connect a computer installs the Runtime and, in the same window, connects that computer; there is no second `agend-runtime connect` command to type. When the window is an interactive console it does what the ZIP's `connect-agend.bat` does: a new profile asks for the one-time pairing code shown on the page, shows the fingerprint and waits for your approval in AgEnD; a profile already paired to this AgEnD reconnects without a code; a computer paired to another AgEnD gets its own profile and the existing pairing is untouched. Anywhere else (an AI agent, CI, a pipeline, `powershell -NonInteractive`) or with `$agendNoConnect = 1` it only installs, prints the exact `agend-runtime connect --server "…"` command to run next and exits with 0. The installer also leaves a reconnect entry (`agend-server.json` with only the public address, and `connect-agend.bat`) under `%LOCALAPPDATA%\agend-runtime\connect\<server>` for a double-click next time, and `agend-runtime` accepts `--connection-dir DIRECTORY` to use such a folder. The install script is still the same fixed bytes pinned by the hash on the page, the pairing code is still typed only into an interactive terminal, and fingerprint comparison and approval are unchanged. Manual commands (install only, and connect) stay on the page, collapsed, for an AI agent or a script. This replaces the earlier statement that the install command "does not connect".
