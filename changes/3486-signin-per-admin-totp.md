- **Sign a new browser in with YOUR OWN authenticator app (#3486).** A browser that is not signed in yet can sign in as one admin with the 6-digit code of that admin's own authenticator (the app set up in Settings → Access & security → Owner verification), on chat fleets and web-only fleets alike. The browser types the admin's name (their chat handle, user id, or `connection:id`) and the code; the session is that admin's own, and their confirmations follow their own rules afterwards (including their own switch). It works on a direct connection (LAN, tailnet, your own proxy) and, on a chat fleet, over a public link; "Only this computer can authorize" closes it. Nothing lists admins and nothing tells a stranger from an admin: a wrong code, an unknown name, an admin with no app and a demoted admin all get the same answer, counted the same way. Each time step is used once (shared with that admin's confirmations); wrong codes are limited per admin, per name typed and fleet-wide; every sign-in is a Notice to all admins. The 8-character sign-in code is unchanged, and an admin with no app keeps using it. The sign-in page for this is temporary: `/signin/authenticator`.
