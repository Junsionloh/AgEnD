- **A computer that asks to pair opens an approval dialog, waiting computers come first, and computers with one name can be told apart.** In **Settings → Runtime** a computer waiting for approval no longer hides its **Approve** far down a long list: the page opens a dialog by itself with the computer's name, host name, platform, when it asked and the **pairing fingerprint in large type** to compare with the one in that computer's terminal. **Approve** still sends the fingerprint, stays off for the first second and does not take the focus; **Reject** drops the request with no second question and refuses (409, nothing revoked) a computer that was approved meanwhile in another tab; **Later**, Esc, the backdrop and × only close it, and a computer put off that way does not open it again by itself. Several waiting computers are shown one at a time, waiting computers come first in the list under a bar ("N computers are waiting for approval", **Review and approve**), a request that has expired opens nothing and is cleared with **Reject**, and computers that share a name get **#1**, **#2**, when they paired and a hint to rename them. A computer that joined with an install command never waits, so it is announced by its own notice instead.
