- **Export an agent's settings, and load a template from a file.** In Details & settings › Basic info, next to Instructions, **Export** writes this agent's saved portable settings — description, tags, Instructions, the inline System prompt, model, tool set, lightweight mode and the behaviour tuning — as `<role>.agend-agent.yaml` (`agend_export: 1`), with a live preview and Copy / Download. Only an allow-list is ever written: accounts, API keys, channel and topic ids, the working folder, machine ids, permissions (`dashboard`, `skipPermissions`), `pre_task_command`, status emojis and the display name never are, and a Description, Instructions or System prompt that looks like a secret blocks the download until it is removed. **Load template** reads such a file (choose it or paste it), shows what will be filled in and what is skipped and why, then fills the form — you still press Save and confirm as usual. The file reserves a `library:` section for skills and tools later. `deploy_template` now also passes a template role's `instructions` to the agent it creates; a template without it deploys exactly as before.
