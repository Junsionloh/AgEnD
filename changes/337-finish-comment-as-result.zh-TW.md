section: Changed

- **完成類的 `task move` 只有 `comment` 沒有 `result` 時，把留言當成結果（AGEND-337）。** agent 把自己的卡移到待確認或完成，總結只寫在 `comment`、`result` 空著，以前會被拒絕；被退回後第二次交回時，卡上還留著上一輪的舊結果，確認的人讀到的就是舊的。現在，卡片的負責人自己完成它（到待確認或完成，第一次或退回後重新交回）時，只給 `comment` 沒給 `result`，就把留言當結果，和 `agend-agent task move ID STATUS "text"` 本來的做法一致，回應裡也會說明。兩個都給時各留各的位置。確認者的備註、人的備註和其他所有的移動仍是留言，退回也仍然不會清掉結果。工具說明寫明了總結要放哪裡。
