- **Fleet 可以要求由你確認 agent 開的主任務（#4569）。** Agent 替你開主任務時用的是自己的工具，卡片沒有你的派工（agent 不能把你設成派工者），最後一張子任務完成後主任務就會自己完成：你沒有機會確認自己要的東西，也沒有任何地方說它做完了。`defaults.task_board.person_confirms_main: true`（設定 › 進階 ›「主任務要等你確認」，預設關閉，不必重啟）會讓每一張 agent 開的主任務進入「審查」，列在「等你處理」，只有你能完成或退回。只改確認這一步：子任務、子任務的問題與確認仍歸開卡的 agent，不會喚醒任何人去確認，負責人仍會被要求收尾，開卡的 agent 會在回覆裡被告知。你自己開的主任務一律等你確認；開關關閉後，已開的卡維持開卡當時的設定。新增一個欄位（`tasks.person_review`），舊版會忽略它。
