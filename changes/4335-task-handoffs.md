- **A main task shows what its sub tasks' agents are really doing, and how the baton passes from one sub task to the next (#4335).** "In progress" is a status, not a sign that an agent is working, so each sub task on a main task's page now has a line under it: a turning ring and what its agent is doing right now ("dev · Edit src/game.js") while it runs — the state alone when steps are not offered (not an admin, the agent's `tool_progress` is off, or Show activity is off) — and, for the others, "Waits for S-1", then "Handed to dev" → "dev read it", or why the hand-over did not arrive (the agent is offline or paused, its task board is off, the notice was lost); a blocked sub task says why, one whose agent waits for you or looks stuck says so, and an idle agent is called idle. The main task's "Agent activity" block lists the same instead of "The work is in its sub tasks", its status gets "Running" while a sub task's agent is, and its activity gains the sub tasks' moves and a row for each hand-over ("S-1 done → handed to dev to start S-2", then where it stands). Nothing starts the next sub task by itself: its assignee is sent one `[Task board]` notice when everything it waited for is done (or when a card is assigned to it) and claims the card itself — the notice and `task get` now say to claim it before starting, and the page says so. An agent that goes ahead and works on its assigned card without claiming it is no longer invisible: while it is working and has no other card, the card's row, the main task's block, the hand-over row, the status and the board's tile show it running, marked "not claimed" (flagged if it stays so for a while); nothing moves the card for it. The state is read from what the dashboard already knows and the steps from the chat's own activity feed, with the same permissions as before; a read-only session sees the state and the sub tasks' moves, not the delivery of a notice. Nothing is rewritten and no data is lost on a downgrade: the new table `task_handoffs` is additive and old code never reads it.
