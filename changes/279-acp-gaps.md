- **ACP agents catch up with terminal ones in six places (#3731).** An ACP instance can run under a named account (`backend_options.<cli>.credential_profile`: grok on its own `GROK_HOME`, agy on `--app_data_dir`; the child gets none of the default account's variables). `auto_pause_after` pauses an idle ACP instance (idle read from the turn, not the screen) and the next message wakes it. The context figure reaches the dashboard, `/ctx` and `/status` (agy's `usage_update`; grok's per-call token report over its model's window). With `skipPermissions: false`, a permission request is also a card in the Telegram or Discord topic (Allow once / Deny / Cancel the turn; fleet admins only). A message sent to a busy ACP agent is queued until the turn ends, as in a terminal (the default); `/steer <message>`, or `steer: true` from another instance, interrupts instead: grok takes it into the running turn through its own `_x.ai/interject` (nothing is cancelled); agy has no such method, so the turn is cancelled and the message runs next in the same session, ahead of the queue. Quota notices stay unsupported (ACP has no quota event). A stopped or signed-out ACP agent's Log no longer points at a View it does not have.
