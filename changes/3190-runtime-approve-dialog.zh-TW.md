- **有電腦要求配對時會跳出核准對話框，等待核准的電腦排在最前面，同名的電腦也分得出來。** 在**設定 → Runtime** 裡，等待核准的電腦不再把它的**核准**按鈕擠到很長的清單底下：頁面會自己跳出對話框，顯示電腦名稱、主機名稱、平台、要求時間，以及**大字的配對指紋**，請和那台電腦終端機上的指紋比對。**核准**仍然帶著指紋送出，對話框出現後的前一秒保持停用，也不會把焦點放在按鈕上；**拒絕**會直接丟掉要求、不再多問一次，而且對在另一個分頁剛被核准的電腦會被拒絕（409，不撤銷任何東西）；**稍後**、Esc、點背景和 × 都只是關掉，按過稍後的電腦不會再自動跳出。同時有好幾台在等時一次顯示一台，等待核准的電腦排在清單最前面，上方有提示條（「有 N 台電腦等待核准」，按「檢視並核准」）；已過期的要求不會跳出，按「拒絕」可以清掉；同名的電腦會標示 **#1**、**#2**、配對時間，並提示可以重新命名。用安裝指令加入的電腦不會經過等待，會改成顯示它自己的通知。
