- **沒有使用你已登入帳號的 agent，現在會說出來（AGEND-340）。** 在設定 → 帳號為 CLI 登入後，登入資料存在具名的 profile 裡，在你選用之前沒有任何 agent 使用它。如果 agent 沒指定帳號、它的 CLI 預設登入已登出、而有具名帳號已登入，以前它會停在 CLI 的登入畫面並暫停，卻沒人說明原因。現在它的對話頁和 Log 頁會說明這個帳號已登入但沒人使用，並提供「選擇帳號」（開啟該 agent 的設定，帳號就在那裡選）；剛好只有一個帳號已登入時，還有「使用 <帳號>」——和設定頁按「儲存」做的是同一個寫入，只有你按下去才會執行。啟動或重新啟動失敗的 toast，以及登入警示，也會帶同一句話。它不會替 agent 選帳號。涵蓋所有有具名帳號的 CLI（Claude Code、Codex、Grok、Antigravity、Kiro），而且只針對這台主機上的 agent。
