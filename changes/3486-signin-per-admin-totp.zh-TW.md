- **新瀏覽器可以用「你自己的」驗證器登入（#3486）。** 還沒登入的瀏覽器，可以用某位管理員自己的驗證器（在「設定 → 存取與安全 → 擁有者驗證」設定的 App）的 6 位數代碼，登入成那位管理員；聊天型和 web-only fleet 都支援。瀏覽器輸入管理員的名稱（聊天帳號代號、使用者 ID，或 `連線:ID`）和代碼；登入後的 session 就是那位管理員自己的，之後的確認照他自己的規則走（包括他自己的開關）。可從直接連線（LAN、tailnet、自己的 proxy）使用，聊天型 fleet 也可從公開連結使用；開啟「Only this computer can authorize」時會被擋下。頁面不會列出管理員，也無法從回應分辨陌生人與管理員：代碼錯誤、名稱不存在、管理員沒綁驗證器、管理員已被降級，回應一律相同，也以相同方式計次。每個時間步只能用一次（與該管理員的逐筆確認共用）；錯誤代碼依每位管理員、每個輸入的名稱和整個 fleet 各自限速；每次登入都會通知所有管理員。8 碼登入碼不變，沒綁驗證器的管理員照舊使用。這個登入頁是暫時的：`/signin/authenticator`。
