- **A fleet can ask you to confirm the main tasks its agents open (#4569).** An agent opens a main task for you with its own tool, so the card has no dispatcher of yours (an agent cannot name you one) and, when its last sub task is done, it finishes by itself: you never get to confirm what you asked for, and nothing says it is done. `defaults.task_board.person_confirms_main: true` (Settings › Advanced › "Main tasks wait for you to confirm them", off by default, no restart) makes every main task an agent opens go to Review and wait under Waiting for you; only you finish it or send it back. It is only the confirmation: its sub tasks, their questions and their confirmations stay with the agent that opened them, nobody is woken to confirm it, its owner is still asked to wrap it up, and the agent is told in the answer that opened it. A main task you open yourself always waits for you. It applies to main tasks opened after the switch is turned on: a card that is already open is not changed, and a card keeps what it was opened with when the switch is turned off. An agent cannot cancel one that waits in Review. One additive column (`tasks.person_review`): an older release ignores it.
